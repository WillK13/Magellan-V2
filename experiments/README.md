# Magellan experiments

`experiments/runs/` contains immutable result bundles generated by the experiment
infrastructure. Run directories are local evidence and are intentionally not committed.
Each bundle contains its own manifest, raw per-node evidence, normalized CSV tables,
summary, and SHA-256 checksum file.

The first validation workload is a checkpointable counter. It exists only to verify
that the measurement pipeline can reconstruct autonomous scheduling decisions and
migration outcomes before paper experiments begin.
